# Core Subsystems (`src/core/`)

Non-GUI backend subsystems for debugger protocol coordination, native plugin loading, configuration persistence, variable models, command routing, and binary inspection.

## Contents

- `Version.hpp`, `Version.cpp`, `VersionConfig.hpp.in`:
  - Build-time semantic version accessors generated by Meson (`GRIDLOCK_VERSION`).
- `commands/`:
  - Command-pattern execution actions (`StepCommand`, `ContinueCommand`, `PauseCommand`) decoupling toolbar and shortcut triggers from backend coordinators.
- `hpc/`:
  - Multi-rank debugger coordinators (`IBackendCoordinator`, `GdbRankCoordinator`, `DapCoordinator`), `clangd` LSP client, Linux `process_vm_readv` memory readers/differs, MPI deadlock analysis, and `/proc` process scanning.
- `managers/`:
  - `ConfigManager` (`config.toml`, `.gridlock/` workspace TOML, `QSettings`, `[plugins] disabled_ids`), `SessionManager`, `ShortcutManager`, `ThemeManager`, `DocsetManager`, and `SpackManager`.
- `models/`:
  - `VariableNode` and `VariableTreeModel` backing lazy stack-frame variable expansion and cross-step value diff highlighting.
- `plugins/`:
  - `PluginManager` (`PluginManager.hpp`, `PluginManager.cpp`): Discovers shared libraries (`.so`, `.dylib`, `.dll`) in `~/.config/gridlock/plugins/` and `<workspace>/.gridlock/plugins/` via `QLibrary` (`ResolveAllSymbolsHint`), validates the frozen C99 ABI v1.0 header in `include/gridlock/plugin_api.h`, enforces `[plugins] disabled_ids`, and dispatches session, stop, and shutdown callbacks.
  - `PluginHostBridge` (`PluginHostBridge.hpp`, `PluginHostBridge.cpp`): Implements every function pointer in `GridLockHostApi` against `GdbRankCoordinator` using thread-safe marshaling, bounded `QEventLoop` + `QTimer` timeouts for `eval_expr` and `read_memory`, and per-plugin variable/command action registries.
- `utils/`:
  - `CliParser`, `ElfBinaryInspector`, `ElfBinaryParser`, `SearchEverywhereEngine`, and `ClangdLspClient` navigation helpers.

## Expected Behavior & Invariants

- **Strict Layer Separation**:
  - Code in `src/core/` avoids `QtWidgets` UI dependencies where possible and communicates state transitions through Qt signals, POD structs, or the C99 plugin ABI.
- **Frozen C99 Plugin ABI Gate**:
  - `PluginManager` rejects any shared library whose `gridlock_plugin_init_v1` status is non-zero, whose `abi_major` differs from `GRIDLOCK_PLUGIN_ABI_MAJOR` (`1`), whose `struct_size` falls outside `[offsetof(GridLockPluginDescriptor, reserved), sizeof(GridLockPluginDescriptor)]`, or whose ID duplicates an already loaded plugin.
  - Unloading or disabling a plugin removes all variable and command actions registered by that plugin before `QLibrary::unload()` runs.
- **Bounded Synchronous Host Queries**:
  - `PluginHostBridge` returns `GRIDLOCK_ERR_NOT_STOPPED` when a target MPI rank is running and `GRIDLOCK_ERR_TIMEOUT` when GDB/MI fails to reply before the timer expires.

## Maintainer & Agent Notes

- Keep every `.hpp` and `.cpp` file in `src/core/plugins/` and modified `ConfigManager` translation units under 500 lines.
- Update subdirectory `README.md` files and refresh the codebase graph whenever adding, splitting, or removing core modules.
